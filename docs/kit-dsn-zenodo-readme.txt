Bitcoin Peer-To-Peer Network Monitoring

We conduct a monitoring of the Bitcoin Peer-to-Peer network since 2015. Our methodology is described in a technical report (https://publikationen.bibliothek.kit.edu/1000091933).
Historical and aggregated statistics are kept up-to-date at https://www.dsn.kastel.kit.edu/bitcoin/.
Further aggregated or raw data is available upon request (see https://www.dsn.kastel.kit.edu/bitcoin/#contact).
